END-TO-END SYSTEM PIPELINE

Statistical & Machine Learning Architecture

How WhereItLands solves international football prediction with rigorous time-series feature engineering and low-scoring dependency adjustment.

STAGE 01

Dynamic Elo Engine

Tracks chronological team strength with dynamic tournament multipliers: FIFA World Cup (K = 60), Continental (K = 50), Qualifiers (K = 40). Includes non-linear goal difference margin scaling M(d).

Tournament K-Weights
STAGE 02

Point-in-Time Features

Extracts 5-match rolling goals scored, goals conceded, defense differentials, and win streaks without lookahead bias, stored in an in-memory columnar Parquet feature store.

Parquet Time-Series
STAGE 03

Stacking Regression

Two-level StackingRegressor blending XGBoost (Poisson loss), LightGBM, and ExtraTrees into a cross-validated RidgeCV meta-estimator to independently predict λhome and λaway.

XGB + LGBM + ExtraTrees
STAGE 04

Coles-Dixon Joint Matrix

Generates a 6×6 bivariate probability matrix corrected with parameter ρ = −0.05 to accurately account for structural dependency in low-scoring football matches (0-0, 1-1).

ρ = −0.05 Correction
